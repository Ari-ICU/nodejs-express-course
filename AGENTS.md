# Content & Localization Guidelines

- **Do NOT translate technical words or programming terms into Khmer**:
  - Keep all technical terms, keywords, types, architectures, and concepts in English (e.g., `Error Envelope`, `Middleware`, `Request`, `Response`, `Production environment`, `Stack Trace`, `Array`, `CPU`, `Database`, `Validation`, `Pagination`, `Cursor`, `Offset`, `Limit`, `Debug`, `Deploy`).
  - Do NOT use awkward literal translations like "បរិស្ថាន" for Environment, "អារេ" for Array, "ស៊ីភីយូ" for CPU, or "ទស្សន៍ទ្រនិច" for Cursor.
  - Khmer should only be used naturally for connective explanations, instructions, and narrative structure.
