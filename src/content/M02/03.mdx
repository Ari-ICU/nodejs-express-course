The project manifest storing metadata, dependencies, scripts, engine compatibility, and module format.

```json
{
  "name": "ecommerce-api",
  "version": "1.0.0",
  "type": "module",
  "main": "src/server.js",
  "scripts": {
    "dev": "node --watch src/server.js",
    "start": "NODE_ENV=production node src/server.js",
    "test": "vitest run"
  },
  "engines": {
    "node": ">=20.0.0"
  }
}
```
