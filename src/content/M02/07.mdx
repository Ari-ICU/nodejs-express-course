Packages required for the application to function in production (e.g., Express, Mongoose, bcrypt, jsonwebtoken).

```json
"dependencies": {
  "bcryptjs": "^2.4.3",
  "cors": "^2.8.5",
  "dotenv": "^16.4.5",
  "express": "^4.19.2",
  "jsonwebtoken": "^9.0.2",
  "mongoose": "^8.3.0"
}
```
