Store secrets in `.env` files for local development, with a documented `.env.example` committed to git.

```javascript
# .env file
PORT=5000
MONGODB_URI=mongodb://localhost:27017/shopdb
JWT_SECRET=super_secret_signing_key_9021
NODE_ENV=development

# In server.js (Node 20+ has native --env-file=.env flag!)
# node --env-file=.env server.js
# Or using dotenv:
import "dotenv/config";
```
