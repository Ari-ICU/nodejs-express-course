Global object providing information and control over the current Node.js process, memory, signals, and uptime.

```javascript
// Graceful shutdown handling
process.on("SIGTERM", () => {
  console.log("SIGTERM received. Closing HTTP server gracefully...");
  server.close(() => {
    mongoose.connection.close();
    process.exit(0);
  });
});
```
