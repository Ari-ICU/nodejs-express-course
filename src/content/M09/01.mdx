### ២. គោលការណ៍ស្នូលទាំង ៣ នៃ REST
* **Resource-Centric**៖ រាល់ Entity សំខាន់ៗ (Users, Products, Orders) សុទ្ធតែមាន URI ផ្ទាល់ខ្លួនច្បាស់លាស់។
* **ប្រើប្រាស់ HTTP ជា Application Protocol**៖ ប្រើប្រាស់ HTTP Verbs ដើម (\`GET\`, \`POST\`, \`PUT\`, \`PATCH\`, \`DELETE\`) ជាជាងការបង្កើត Action Verbs ក្នុង URL។
