Resource-oriented endpoints: GET (retrieve), POST (create), PUT (replace), PATCH (partial update), DELETE (remove).

```javascript
// Consistent REST design
// GET    /api/v1/articles        -> List articles
// POST   /api/v1/articles        -> Create new article
// GET    /api/v1/articles/:id    -> Get single article
// PATCH  /api/v1/articles/:id    -> Partial update
// DELETE /api/v1/articles/:id    -> Remove article
```
