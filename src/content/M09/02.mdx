Consistent JSend/JSON-API envelopes with success boolean, data payload, meta information, and status codes.

```javascript
// Consistent envelope pattern
res.status(200).json({
  success: true,
  statusCode: 200,
  meta: {
    page: 1,
    limit: 10,
    totalRecords: 142,
    totalPages: 15
  },
  data: items
});
```
