### 1. ប្រភេទនៃធនធាន
** ធនធានឯកសារ **៖ វត្ថុតែមួយ ឬវត្ថុទិន្នន័យទិន្នន័យ (ឧ. \\`/users/usr_101\`).
* **Collection Resource**: A server-managed directory of resources (e.g., \`/users\`, \`/articles\`).
* **Store Resource**: A client-managed resource repository where the client determines the URI on creation (e.g., \`PUT /files/document.pdf\`).
* **Controller Resource**: An executable procedure or workflow that doesn't map directly to CRUD (e.g., \`POST /auth/login\`, \`POST /cart/checkout\`).

### 2. Resources vs Representations
Clients never directly touch the physical database row; instead, they receive a **Representation** of that resource (usually serialised JSON). The server may omit internal fields like \`password_hash\`, format dates into ISO-8601 strings, and compute dynamic fields like \`fullName\` or \`discountedPrice\`.`,
