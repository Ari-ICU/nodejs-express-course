### 1. Types of Resources
* **Document Resource**: A single object or database record instance (e.g., \`/users/usr_101\`).
* **Collection Resource**: A server-managed directory of resources (e.g., \`/users\`, \`/articles\`).
* **Store Resource**: A client-managed resource repository where the client determines the URI on creation (e.g., \`PUT /files/document.pdf\`).

### 2. Resources vs Representations
