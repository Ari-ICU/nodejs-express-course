### 1. Two Standard Retrieval Patterns
* **Collection Route (\`GET /api/v1/products\`)**: Fetches a list of resources. Supports dynamic filtering via URL query parameters (\`req.query\`), such as category matching, price filters, and pagination.
* **Single Item Route (\`GET /api/v1/products/:id\`)**: Uses route path parameters (\`req.params\`) to fetch a unique entity by its identifier.

### 2. Status Code & Response Rules
* **200 OK**: Returned for successful data lookups, wrapped in a uniform JSON envelope containing metadata and the \`data\` payload.
* **404 Not Found**: Returned immediately when a specific resource ID does not exist in the database or collection.
