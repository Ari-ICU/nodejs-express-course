### 1. Key Engineering Rules for PATCH
* **Differential Updates**: The server merges incoming changes onto the existing resource representation.
* **Mass Assignment Protection**: Never blindly assign \`req.body\` (e.g., \`Object.assign(item, req.body)\`). Malicious clients could overwrite sensitive protected fields like \`role: "admin"\`, \`id\`, or \`balance\`. Always whitelist permitted fields.
* **Payload Validation**: Validate only the fields that are actually provided in the request body. If a field is omitted, skip its validation.
* **Status Codes**: Return **200 OK** with the updated resource representation, or **404 Not Found** if the resource identifier doesn't exist.`,
