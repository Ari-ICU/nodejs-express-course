### ១. សមាសធាតុចម្បងនៃ Enterprise Error Envelope
* **\`success: false\`**៖ បញ្ជាក់យ៉ាងច្បាស់ថា request មិនជោគជ័យ។
* **\`error.code\` (string)**៖ អក្សរធំតំណាងឱ្យ Machine-readable error code ដូចជា \`EMAIL_ALREADY_EXISTS\`, \`TOKEN_EXPIRED\`, ឬ \`PAYMENT_DECLINED\`។ ចំណុចនេះជួយឱ្យ Frontend អាច map ទៅ UI Error Message ជាភាសាខ្មែរបាន ដោយមិនចាំបាច់ parse message string ឡើយ។
* **\`error.message\` (string)**៖ សេចក្តីសង្ខេប human-readable message អំពី error ដែលបានកើតឡើង។
* **\`error.details\` (array, optional)**៖ List លម្អិតនៃ errors តាម field នីមួយៗនៅពេល validation fail។
* **\`error.timestamp\` (ISO-8601)**៖ Timestamp សម្រាប់ debug និង verify ជាមួយ Error Logs លើ Server។
