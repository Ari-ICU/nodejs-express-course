NoSQL document stores format data as flexible JSON-like BSON documents, allowing nested objects and arrays without complex joins.

```javascript
// A MongoDB Document (BSON):
{
  "_id": ObjectId("65f1a2b3c4d5e6f7a8b9c0d1"),
  "title": "MacBook Pro M3",
  "price": 1999.00,
  "tags": ["laptop", "apple", "hardware"],
  "specs": { "ram": "32GB", "storage": "1TB SSD" },
  "reviews": [
    { "user": "Chann", "rating": 5, "comment": "Blazing fast!" }
  ],
  "createdAt": ISODate("2026-03-15T08:00:00Z")
}
```
