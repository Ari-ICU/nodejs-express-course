Automatically save JWT tokens into Postman environment variables upon login for seamless authenticated requests.

```javascript
// Postman Tests Tab (Runs automatically after Login request):
const response = pm.response.json();
if (response.accessToken) {
  pm.environment.set("jwt_token", response.accessToken);
  console.log("Token automatically saved to environment!");
}

// In subsequent requests Headers:
// Authorization: Bearer {{jwt_token}}
```
