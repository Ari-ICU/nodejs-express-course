// Why Socket.IO over raw ws:
// 1. Reliability: Falls back to HTTP long-polling if corporate firewalls block WebSockets
// 2. Auto-reconnect: Automatically reconnects and flushes buffered messages
// 3. Named Events: emit("order:paid", payload) instead of JSON.stringify({ type: ... })
// 4. Broadcasting: Easily emit to all clients EXCEPT sender: socket.broadcast.emit(...)
// 5. Rooms: Group sockets into virtual channels: socket.join("room-123")
