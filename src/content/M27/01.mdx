```bash
src/
├── config/         # Environment vars, database connections, logger
├── controllers/    # [C in MVC] Request/response handling, HTTP status codes
├── services/       # Core business logic, data calculations, 3rd party APIs
├── models/         # [M in MVC] Mongoose schemas and database models
├── routes/         # Express router endpoint definitions
├── middleware/     # Auth, error handling, rate limiters, upload guards
├── validators/     # Zod/Joi request validation schemas
├── utils/          # AppError class, formatters, helpers
├── jobs/           # BullMQ queue producers and workers
└── app.js          # Express app assembly (no listen())
```
